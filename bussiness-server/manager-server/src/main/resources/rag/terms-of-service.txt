本文档为吉利航空后台管理系统的管理员模块业务操作规范与数据说明，供内部管理人员参考。
1. 管理员（系统用户）信息管理
- 管理人员拥有对系统管理员记录的完全操作权限（增删改查），无需进行额外身份验证。
- 查询条件支持：用户ID、用户名，支持模糊查询和分页。
- 查询"所有管理员"或"所有用户"时，直接返回全部数据，支持分页展示。
- 新增管理员：需提供用户名、密码、昵称等信息。
- 修改管理员：可修改用户名、昵称、状态等信息，通过用户ID定位记录。
- 删除管理员：通过用户ID定位记录并执行删除，支持批量删除。
2. 角色信息管理
- 管理人员拥有对系统角色记录的完全操作权限（增删改查）。
- 查询条件支持：角色ID、角色名称，支持模糊查询和分页。
- 新增角色：需提供角色名称、角色描述等信息。
- 修改角色：可修改角色名称、描述等信息，通过角色ID定位记录。
- 删除角色：通过角色ID定位记录并执行删除，支持批量删除。
- 查询所有角色列表时，直接返回全部角色数据。
3. 菜单权限信息管理
- 管理人员拥有对系统菜单权限记录的完全操作权限（增删改查）。
- 查询所有菜单权限时，返回完整的权限树结构。
- 新增权限：需提供权限名称、权限标识、类型（菜单/按钮）、父级ID等信息。
- 修改权限：可修改权限名称、标识、排序、状态等信息，通过菜单ID定位记录。
- 删除权限：通过菜单ID定位记录并执行删除。
4. 系统操作日志查询（仅查询）
- 管理人员可查询系统操作日志，但不可对日志执行增删改操作。
- 查询条件支持：用户ID、操作描述，支持模糊查询和分页。
- 日志信息字段：日志ID、用户ID、操作描述、请求方法、请求参数、IP地址、创建时间。
5. 操作注意事项
- 执行删除操作前应向管理人员确认目标记录。
- 批量操作时建议先查询确认再执行。
- 如管理人员的指令不明确，应主动询问具体操作对象和操作类型。
- 管理员密码在数据库中为加密存储，不可明文查询。

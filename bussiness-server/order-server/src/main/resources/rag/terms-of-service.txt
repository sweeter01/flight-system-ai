本文档为吉利航空后台管理系统订单管理模块的业务操作规范与数据说明，供内部管理人员参考。

1. 乘客信息管理
- 管理人员对乘客信息拥有查询权限，可根据姓名、年龄范围、性别、身份证号、用户名等条件查询乘客列表，支持模糊查询和分页展示。
- 查询"所有乘客"或"全部记录"时，直接返回全部数据，支持分页。
- 可根据乘客ID查询该乘客的所有历史订单详情，包含航班预订记录和优惠券信息。

2. 订单信息管理
- 管理人员对订单记录拥有查询、修改、删除和取消权限，无需进行额外身份验证。
- 查询条件支持：订单编码、用户姓名、订单状态、支付方式，支持分页展示。
- 订单状态说明：0-待支付，1-已支付，2-已取消，3-已完成。
- 支付方式说明：ALIPAY-支付宝，WECHAT-微信，CREDIT-信用卡，DEBIT-借记卡。
- 取消订单：根据航班预订号取消订单，将订单状态设为已取消（2）。仅待支付（0）和已支付（1）状态的订单可取消。
- 删除订单：批量删除订单，仅建议删除已取消或已完成的订单。

3. 优惠券管理
- 管理人员对优惠券记录拥有查询权限，可根据优惠券编码、类型、名称、状态查询优惠券列表。
- 优惠券类型说明：0-折扣券，1-满减券，2-无门槛券。
- 优惠券状态说明：0-可用，1-不可用。

4. 数据字段说明
4.1 乘客（Passenger）
- id：乘客唯一标识，自增主键。
- name：乘客姓名。
- age：年龄。
- sex：性别。
- phone：手机号。
- email：邮箱。
- certificate：身份证号。
- username：用户名。
- createTime：记录创建时间。

4.2 订单（Order）
- id：订单唯一标识，自增主键。
- orderCode：订单编码，唯一标识一个订单。
- bookingNumber：航班预订号。
- passengerId：乘客ID。
- passengerName：乘客姓名。
- discount：折扣（如8折为8）。
- couponCode：使用的优惠券编码。
- paymentMethod：支付方式。
- status：订单状态（0待支付/1已支付/2已取消/3已完成）。
- primePrice：原价。
- totalPrice：实付金额。
- comment：备注。
- createTime：记录创建时间。
- updateTime：记录更新时间。

4.3 优惠券（Coupon）
- id：优惠券唯一标识，自增主键。
- couponName：优惠券名称。
- couponCode：优惠券编码。
- couponType：优惠券类型（0折扣券/1满减券/2无门槛券）。
- couponPrice：面值或折扣金额。
- status：状态（0可用/1不可用）。
- createTime：记录创建时间。
- updateTime：记录更新时间。

5. 操作注意事项
- 执行取消或删除操作前应向管理人员确认目标记录。
- 批量操作时建议先查询确认再执行。
- 订单编码应为唯一值，查询时可直接通过编码精确定位。
- 如管理人员的指令不明确，应主动询问具体操作对象和操作类型。
- 查询时如果不指定条件，将返回所有记录列表，建议配合分页使用。
